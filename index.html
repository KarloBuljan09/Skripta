Kako dodati CSS u HTML

Danas smo učili kako povezati CSS sa HTML-om. Postoje tri načina:

  • Inline CSS: direktno u elementu, npr. <p style="color:red;">
  • Internal CSS: unutar <style> taga u <head>
  • External CSS: povezivanje vanjskog .css fajla koristeći <link>

Uglavnom koristimo vanjski CSS jer je najorganiziraniji i lakši za održavanje.

CSS Box Model

CSS box model opisuje kako se HTML elementi prikazuju kao pravokutnici na stranici.

  • Content: Sadržaj (tekst, slike...)
  • Padding: Prazan prostor oko sadržaja
  • Border: Okvir oko paddinga
  • Margin: Vanjski razmak između elemenata

Sve ove komponente utiču na konačne dimenzije i poziciju elementa.

Uređivanje pozadinske grafike u Box modelu

Pozadinska grafika se postavlja pomoću CSS svojstva background, a može se prilagoditi veličina, pozicija i ponavljanje unutar box modela

  • Background-image: Postavlja sliku kao pozadinu elementa
  • Background-size: Određuje veličinu pozadinske slike (npr. cover, contain, ili konkretne dimenzije)
  • Background-position: Pomiče sliku unutar elementa (npr. center, top left)
  • Background-repeat: Određuje ponavlja li se slika (repeat, no-repeat, itd.)
  • Background-clip: Kontrolira do kojeg dijela box modela se pozadina prikazuje (npr. content-box, padding-box, border-box)

Kombinacijom ovih svojstava možemo precizno kontrolirati kako se pozadinska grafika prikazuje unutar svakog dijela box modela.

Opacity - Gradients

Svojstva opacity i gradient koriste se za postizanje vizualnih efekata kao što su prozirnost i prijelazi boja.

  • Opacity: Određuje prozirnost cijelog elementa (vrijednosti od 0 do 1, gdje je 0 potpuno prozirno, a 1 potpuno vidljivo)
  • RGBA boje: Omogućuju postavljanje prozirnosti samo na boju pomoću četvrte vrijednosti (npr. rgba(0, 0, 0, 0.5))
  • Linear-gradient: Stvara prijelaz između dvije ili više boja u ravnoj liniji
  • Radial-gradient: Stvara kružni ili eliptični prijelaz boja koji se širi iz središta
  • Transparent: Koristi se za potpuno prozirne dijelove u gradientima

Korištenjem prozirnosti i prijelaza možemo poboljšati izgled elemenata i dodati vizualnu dubinu web stranici.

Sjene i zaobljeni rubovi

Svojstva za sjene i zaobljene rubove koriste se za estetsko poboljšanje elemenata na stranici.

  • Box-shadow: Dodaje sjenku oko cijelog elementa (može se podešavati pomak, razmazanost, boja)
  • Text-shadow: Dodaje sjenku na tekst (omogućava efekte poput sjene ili svjetlucanja)
  • Border-radius: Zaobljuje rubove elemenata (vrijednosti u pikselima ili postocima, npr. 10px, 50%)
  • Inset shadow: Unutrašnja sjenka (kada se koristi inset unutar box-shadow)
  • Multiple shadows: Moguće je dodati više sjenki odjednom, odvojene zarezima

Sjene i zaobljeni rubovi doprinose modernijem i privlačnijem dizajnu korisničkog sučelja.

CSS Pozicioniranje

Svojstva za pozicioniranje u CSS-u omogućavaju kontrolu nad položajem elemenata na stranici. Postoji pet osnovnih tipova pozicioniranja: static, relative, absolute, fixed i sticky.

  • Static: Zadana vrijednost za sve elemente. Element se pozicionira u toku dokumenta bez posebnog podešavanja položaja.
  • Relative: Element se pozicionira u odnosu na svoj originalni položaj. Pomaci (top, left, right, bottom) utiču samo na vizualni prikaz.
  • Absolute: Element se pozicionira u odnosu na najbližeg roditelja koji nije static. Ispada iz normalnog toka dokumenta.
  • Fixed: Element se pozicionira u odnosu na prozor preglednika i ostaje na mjestu čak i pri skrolanju stranice.
  • Sticky: Kombinacija relative i fixed. Element se ponaša kao relativan dok ne dođe do određene točke skrolanja, nakon čega „prilijepi“ (postane fiksiran).

Razumijevanje različitih tipova pozicioniranja ključno je za pravilno raspoređivanje i organizaciju elemenata u web dizajnu.

CSS Flexbox

Flexbox (Flexible Box Layout) je model rasporeda u CSS-u koji omogućava jednostavno i fleksibilno poravnanje i raspored elemenata unutar kontejnera. Omogućava prilagođavanje elemenata različitim veličinama ekrana.

  • display: flex; Aktivira flexbox raspored unutar kontejnera. Svi njegovi direktni potomci postaju flex elementi.
  • flex-direction: Određuje smjer glavne osi — može biti row, row-reverse, column ili column-reverse.
  • justify-content: Poravnava elemente duž glavne osi (center, space-between, space-around, itd.).
  • align-items: Poravnava elemente duž poprečne osi (flex-start, center, stretch, itd.).
  • flex-wrap: Omogućava prelamanje elemenata u novi red ako nema dovoljno prostora (wrap, nowrap, wrap-reverse).
  • align-content: Poravnava više redova elemenata kada se koristi flex-wrap.
  • gap: Postavlja razmak između flex elemenata bez potrebe za marginama.

Flexbox olakšava izradu responzivnih i dinamičnih rasporeda, smanjujući potrebu za kompliciranim CSS pravilima i floatovima.

Responzivni prikaz

Responzivni dizajn omogućava da se web stranica automatski prilagodi različitim uređajima i veličinama ekrana. Cilj je osigurati da sadržaj uvijek bude čitljiv i funkcionalan — bez potrebe za zumiranjem ili horizontalnim skrolanjem.

Osnovni principi responzivnog dizajna

  • Fluidni raspored: Umjesto fiksnih širina (u px), koriste se postotci (%) ili fleksibilne jedinice (em, rem, vw, vh).
  • Media query: Omogućava primjenu različitih CSS stilova ovisno o širini uređaja.
  • Fleksibilne slike: Slike se prilagođavaju veličini kontejnera pomoću max-width: 100%;.
  • Mobilni pristup: Dizajn se često prvo radi za manje ekrane ("mobile-first"), pa se postepeno prilagođava većim.

Primjer 1: Fleksibilni raspored


.container {
  width: 90%;
  margin: 0 auto;
}
img {
  max-width: 100%;
  height: auto;
}

Ovim kodom osiguravamo da se kontejner i slike automatski smanje ili povećaju ovisno o veličini ekrana.

Primjer 2: Media query


/* Osnovni stil za male ekrane */
body {
  font-size: 16px;
  background-color: #f4f4f4;
}

/* Veći ekrani (tableti i računala) */
@media (min-width: 768px) {
  body {
    font-size: 18px;
    background-color: #fff;
  }
}

/* Široki ekrani (desktop) */
@media (min-width: 1200px) {
  body {
    font-size: 20px;
    max-width: 1200px;
    margin: auto;
  }
}

Ovim pristupom CSS mijenja izgled stranice ovisno o širini prozora preglednika.

Primjer 3: Responzivni raspored s Flexboxom


.container {
  display: flex;
  flex-wrap: wrap;
  gap: 10px;
}

.box {
  flex: 1 1 300px;
  background-color: lightblue;
  padding: 20px;
  text-align: center;
}

Ovim primjerom elementi (.box) se automatski prelamaju u novi red kada nema dovoljno prostora — idealno za mobilne uređaje.

Zaključak: Responzivni dizajn je ključan dio modernog web razvoja, jer omogućava pristupačnost i funkcionalnost na svim uređajima.

PSEUDOKLASE

Pseudoklase u CSS-u omogućavaju stilizaciju elemenata na temelju njihovog stanja ili položaja u dokumentu. Koriste se s dvotočkom (:) i dopunjuju selektore bez potrebe za dodatnim klasama ili ID-jevima.

Osnovne pseudoklase

  • :hover — stil kada korisnik prelazi mišem preko elementa
  • :active — stil u trenutku klika na element
  • :focus — stil kada je element u fokusu (npr. input, link)
  • :visited — stil za već posjećene linkove
  • :first-child — prvi potomak unutar roditelja
  • :last-child — zadnji potomak unutar roditelja
  • :nth-child(n) — n-ti potomak (n može biti broj, even, odd ili formula)

Primjer: hover i focus


a:hover {
  color: #0066cc;
  text-decoration: underline;
}
input:focus {
  outline: 2px solid #0066cc;
  border-color: #0066cc;
}

Primjer: nth-child za redove tablice


tr:nth-child(odd) {
  background-color: #f9f9f9;
}
tr:nth-child(even) {
  background-color: #fff;
}

Zaključak: Pseudoklase su moćan način za dinamičnu stilizaciju bez dodatnog HTML-a i često se koriste za interaktivnost i čitljivost sadržaja.
