Kako dodati CSS u HTML

Danas smo učili kako povezati CSS sa HTML-om. Postoje tri načina:

  • Inline CSS: direktno u elementu, npr. <p style="color:red;">
  • Internal CSS: unutar <style> taga u <head>
  • External CSS: povezivanje vanjskog .css fajla koristeći <link>

Uglavnom koristimo vanjski CSS jer je najorganiziraniji i lakši za održavanje.

CSS Box Model

CSS box model opisuje kako se HTML elementi prikazuju kao pravougaonici na stranici.

  • Content: Sadržaj (tekst, slike...)
  • Padding: Prazan prostor oko sadržaja
  • Border: Okvir oko paddinga
  • Margin: Vanjski razmak između elemenata

Sve ove komponente utiču na konačne dimenzije i poziciju elementa.

Uređivanje pozadinske grafike u Box modelu

Pozadinska grafika se postavlja pomoću CSS svojstva background, a može se prilagoditi veličina, pozicija i ponavljanje unutar box modela

  • Background-image:Postavlja sliku kao pozadinu elementa
  • Background-size:Određuje veličinu pozadinske slike (npr. cover, contain, ili konkretne dimenzije)
  • Background-position:Pomiče sliku unutar elementa (npr. center, top left)
  • Background-repeat:Određuje ponavlja li se slika (repeat, no-repeat, itd.)
  • Background-clip:Kontroliše do kojeg dijela box modela se pozadina prikazuje (npr. content-box, padding-box, border-box)

Kombinacijom ovih svojstava možemo precizno kontrolirati kako se pozadinska grafika prikazuje unutar svakog dijela box modela.

Opacity - Gradients

Svojstva opacity i gradient koriste se za postizanje vizualnih efekata kao što su prozirnost i prijelazi boja.

  • Opacity:Određuje prozirnost cijelog elementa (vrijednosti od 0 do 1, gdje je 0 potpuno prozirno, a 1 potpuno vidljivo)
  • RGBA boje:Omogućuju postavljanje prozirnosti samo na boju pomoću četvrte vrijednosti (npr. rgba(0, 0, 0, 0.5))
  • Linear-gradient:Stvara prijelaz između dvije ili više boja u ravnoj liniji
  • Radial-gradient:Stvara kružni ili eliptični prijelaz boja koji se širi iz središta
  • Transparent:Koristi se za potpuno prozirne dijelove u gradientima

Korištenjem prozirnosti i prijelaza možemo poboljšati izgled elemenata i dodati vizualnu dubinu web stranici.

Sjene i zaobljeni rubovi

Svojstva za sjene i zaobljene rubove koriste se za estetsko poboljšanje elemenata na stranici.

  • Box-shadow:Dodaje sjenku oko cijelog elementa (može se podešavati pomak, razmazanost, boja)
  • Text-shadow:Dodaje sjenku na tekst (omogućava efekte poput sjene ili svjetlucanja)
  • Border-radius:Zaobljuje rubove elemenata (vrijednosti u pikselima ili postocima, npr. 10px, 50%)
  • Inset shadow:Unutrašnja sjenka (kada se koristi inset unutar box-shadow)
  • Multiple shadows:Moguće je dodati više sjenki odjednom, odvojene zarezima

Sjene i zaobljeni rubovi doprinose modernijem i privlačnijem dizajnu korisničkog sučelja.
